# Contributing

Thank you for contributing to CasterLiveAutomation. **Created by @Alessio278.**

Before submitting a pull request: describe the problem, explain why the change is needed, include tests where practical, and avoid modifying unrelated parts of the scheduler. Windows GUI work requires screenshots or a manual test record from the exact version being changed.

Use two-component public versions (`1.0`, `1.1`, etc.), simple hyphens (`-`) in public text and do not publish personal settings, coordinates or broadcast logs. Follow [AI_PROJECT_INSTRUCTIONS.md](AI_PROJECT_INSTRUCTIONS.md), [PROJECT_STATE.md](PROJECT_STATE.md) and [docs/RELEASE_PROCESS.md](docs/RELEASE_PROCESS.md).

Public identity: `Created by @Alessio278`. Preserve any third-party copyright/license terms. File issues with minimal redacted logs; for vulnerabilities follow [SECURITY.md](SECURITY.md).
