# Security policy

CasterLiveAutomation performs UI automation against a third-party application. It is not designed to enforce security boundaries or confirm that an audio stream is online.

**Report sensitive vulnerabilities privately** using the repository's GitHub security advisory feature where available. Do not post passwords, credentials, IPs, personal configuration files, captured coordinates, or unredacted logs in public Issues.

The maintainers do not promise unattended broadcast continuity. Windows and CasterLive DJ compatibility must be verified on real installations; see [docs/CLICK_SAFETY.md](docs/CLICK_SAFETY.md).

The repository is community-maintained, not affiliated with the developer of CasterLive DJ.
