# Language coverage

Supported interface language choices: **IT, EN, ES, FR**. The GUI saves the selected language locally in `CasterLiveAutomation_Settings.ini`.

README pages are provided in English ([root](../README.md)), [Italian](README.it.md), [Spanish](README.es.md), and [French](README.fr.md).

**Known gap:** some advanced dialogs and technical Worker logs remain in Italian; the presence of four language choices does not certify fully translated workflows. Full UI translation and Windows pixel/label checks are V1.0 acceptance items, not presumed complete.

Use the simple hyphen (`-`) in documentation and UI text when editing (StagePad shared convention); avoid replacing existing runtime action tokens.
